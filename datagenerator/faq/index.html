Questions fréquentes

Dahoni Data Generator est une application Salesforce native et gratuite qui génère des données de test réalistes sur n'importe quel objet standard ou personnalisé, sans code ni CSV. Voici les réponses aux questions les plus courantes.

Qu'est-ce que Dahoni Data Generator ?

Dahoni Data Generator est une application Salesforce native et gratuite qui génère des données de test réalistes sur n'importe quel objet standard ou personnalisé, sans code ni CSV.

Data Generator est-il gratuit ?

Oui. Data Generator est gratuit, disponible dès maintenant en version bêta en attendant sa publication sur l'AppExchange.

Sur quels objets Salesforce Data Generator fonctionne-t-il ?

Data Generator fonctionne sur tout objet standard ou personnalisé de votre org, y compris les objets de managed packages comme CPQ (par exemple SBQQ__Quote__c).

Data Generator peut-il générer des objets liés entre eux ?

Oui. Vous pouvez générer en une seule exécution des objets liés entre eux via des champs de référence, ainsi que des objets totalement indépendants dans le même run.

Les données générées sortent-elles de mon org Salesforce ?

Non. Data Generator ne fait aucun callout externe : toutes les données générées restent à l'intérieur de votre org Salesforce. Voir la page Sécurité et RGPD pour le détail.

Sur quels types d'org puis-je utiliser Data Generator ?

Vous pouvez générer des données sur une Developer Org, une scratch org ou une sandbox. Un garde-fou intégré empêche toute génération accidentelle sur une org de production.

Comment installer Dahoni Data Generator ?

Depuis la page d'installation, choisissez le lien correspondant à votre org (dev/scratch ou sandbox), renseignez vos informations, puis installez le package. Assignez-vous ensuite le permission set « Data Generator User ». Le détail est expliqué dans le guide de démarrage rapide.

Qu'est-ce qu'un template dans Data Generator ?

Un template est une configuration de génération réutilisable : objets, champs, règles de génération. Un template Sample (Sales Cloud) est fourni à l'installation, et vous pouvez créer et sauvegarder vos propres templates.

Puis-je supprimer les données générées ?

Oui. Data Generator permet de supprimer en un clic tous les enregistrements créés lors d'une génération donnée.

Data Generator garde-t-il un historique des générations ?

Oui. Chaque génération est enregistrée dans un historique qui indique le nombre d'enregistrements créés, la date et les éventuelles erreurs.

Data Generator peut-il s'exécuter automatiquement après un rafraîchissement de sandbox ?

Oui, via le SandboxPostCopyHandler natif de Salesforce : configurez un template pour qu'il s'exécute automatiquement à chaque refresh de la sandbox.

Dans quelles langues Data Generator est-il disponible ?

L'interface et les données générées sont disponibles en français et en anglais.
