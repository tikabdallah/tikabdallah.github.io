Démarrage rapide

Voici les étapes pour installer Dahoni Data Generator et lancer votre première génération de données de test, en quelques minutes.

1. Installer le package

Depuis la page d'installation, choisissez le lien correspondant à votre org : Developer org / scratch org, ou sandbox. Renseignez vos informations pour recevoir le lien d'installation du package bêta.

2. Assigner le permission set

Une fois le package installé, assignez-vous le permission set « Data Generator User ». C'est lui qui donne accès à l'application.

3. Lancer votre première génération

  1. Ouvrez l'App Launcher et recherchez Data Generator.
  2. Sélectionnez New Generation from a Template.
  3. Choisissez le template Sample (Sales Cloud), fourni dès l'installation.
  4. Cliquez sur Create.
  5. Cliquez sur Save & Run.

Vos enregistrements de test sont créés en quelques secondes. La génération est enregistrée dans l'historique de l'application, avec le nombre d'enregistrements créés, la date, et les éventuelles erreurs.

Et après ?

Une fois à l'aise avec le template Sample, vous pouvez créer vos propres templates, ajouter des objets liés via des champs de référence, et configurer l'automatisation sur rafraîchissement de sandbox.
