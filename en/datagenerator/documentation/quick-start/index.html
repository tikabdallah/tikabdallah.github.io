Quick start

Here are the steps to install Dahoni Data Generator and run your first test data generation, in a few minutes.

1. Install the package

From the installation page, choose the link that matches your org: Developer org / scratch org, or sandbox. Fill in your details to receive the install link for the beta package.

2. Assign the permission set

Once the package is installed, assign yourself the "Data Generator User" permission set. This is what grants access to the app.

3. Run your first generation

  1. Open the App Launcher and search for Data Generator.
  2. Select New Generation from a Template.
  3. Choose the Sample template (Sales Cloud), included on install.
  4. Click Create.
  5. Click Save & Run.

Your test records are created in seconds. The run is logged in the app's history, with the number of records created, the date, and any errors.

What's next?

Once you're comfortable with the Sample template, you can create your own templates, add linked objects through reference fields, and configure automation on sandbox refresh.
