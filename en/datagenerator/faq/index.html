Frequently asked questions

Dahoni Data Generator is a free, native Salesforce app that generates realistic test data on any standard or custom object, with no code and no CSV. Here are the answers to the most common questions.

What is Dahoni Data Generator?

Dahoni Data Generator is a free, native Salesforce app that generates realistic test data on any standard or custom object, with no code and no CSV.

Is Data Generator free?

Yes. Data Generator is free and available now as a beta, ahead of its release on the AppExchange.

Which Salesforce objects does Data Generator support?

Data Generator works on any standard or custom object in your org, including managed package objects such as CPQ's SBQQ__Quote__c.

Can Data Generator create linked objects?

Yes. You can generate related objects linked through reference fields, and fully independent objects, in the same run.

Does generated data ever leave my Salesforce org?

No. Data Generator makes no external callouts: everything stays inside your Salesforce org. See the Security and GDPR page for details.

Which org types can I use Data Generator on?

You can generate data on a Developer Org, a scratch org, or a sandbox. A built-in safeguard prevents accidental generation on a production org.

How do I install Dahoni Data Generator?

From the installation page, choose the link that matches your org (dev/scratch or sandbox), fill in your details, and install the package. Then assign yourself the "Data Generator User" permission set. See the quick start guide for details.

What is a template in Data Generator?

A template is a reusable generation configuration: objects, fields, generation rules. A Sample template (Sales Cloud) is included on install, and you can create and save your own templates.

Can I delete the generated data?

Yes. Data Generator lets you delete, in one click, all records created by a given generation run.

Does Data Generator keep a history of generations?

Yes. Every generation is logged in a history that shows the number of records created, the date, and any errors.

Can Data Generator run automatically after a sandbox refresh?

Yes, through Salesforce's native SandboxPostCopyHandler: configure a template to run automatically on every sandbox refresh.

What languages is Data Generator available in?

The interface and the generated data are available in French and English.
